# LIFELOG v2.8 — Bubu & Dudu Reference Asset Integration

Built from the LIFELOG v2.7 project and the organized Bubu_Dudu_Assets_Clean_HD pack.

## Integrated
- 48 category illustrations: 16 activities each for Bubu, Dudu and Together.
- 54 outfit previews: 18 Bubu, 18 Dudu and 18 matching Together looks.
- Home category cards now use the matching activity art (Bubu, Dudu or both).
- Sleep and Wake Up quick-record cards use their own character illustrations.
- Record forms show the matching category illustration.
- Settings includes separate Bubu, Dudu and Together outfit galleries with saved selections.
- Home displays the saved individual and matching outfit selections when the Bubu & Dudu theme is active.
- Existing LifeLog features, records, videos, and Light/Dark/Original themes are preserved.
- Service worker cache version updated and all new PNGs precached.

## Test
1. Export a LIFELOG backup in Settings > Backup & restore.
2. Extract this ZIP.
3. Upload the contents of the `lifelog_v2` folder to the GitHub Pages repository root.
4. Open Settings > Appearance > Bubu & Dudu (Character Theme).
5. Check Home, category cards, category record forms, and Settings > Bubu & Dudu outfit choices.
6. If an old screen remains cached, close the app and reload the page after the service worker updates.

## Asset note
The images are individual PNG files, organized by character and activity. They are based on the reference-based Bubu/Dudu asset collection, not generated placeholder vector bears. The source PNGs have their original image backgrounds; they are not transparent.
